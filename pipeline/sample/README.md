## How to choose

- **Explaining something?** → A1.1 / B1 (minimal) or B2 (friendly color)
- **Telling a story?** → A4 (cozy), A2.2 (cinematic), A6 (noir), B4 (thriller)
- **Selling / teaching tech?** → A2.1 (modern pop)
- **Funny / meme energy?** → B3 (retro TV) or B5 (character explainer)
- **History?** → A5 (historical cartoon)
